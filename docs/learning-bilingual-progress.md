# Learning 双语功能验证记录

## 实现

- `/learning` 默认为中文库；`/learning/en` 为英文库。
- 首页、分类页、阅读页均提供明显的语言切换，阅读页切换后保留文章。
- 列表卡片和文章页展示双语标题，搜索匹配两种标题。
- 五篇现有笔记均有完整英文译本；中文原始文件保持不变。
- 英文译文使用独立 Markdown 文件和原文 SHA-256 校验，不需要线上翻译 API、密钥或后端。
- 新增笔记、分类和译文的方法见 `docs/learning.md`。未完成或草稿译文不生成英文文章页，中文页显示待译状态。
- 渲染层修复表格数学表达式中的未转义竖线，同时保留代码示例原貌。
